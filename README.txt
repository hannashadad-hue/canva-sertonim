מדריך אינטראקטיבי: מהרעיון לסרטון מונפש

1. פתחו את index.html בדפדפן (אפשר גם ללא חיבור אינטרנט).
2. כדי לפרסם ברשת: העלו את כל תכולת התיקייה, כולל images, למאגר ציבורי ב-GitHub.
3. הפעילו Settings > Pages > Deploy from a branch, main, /root.
4. הקישור יופיע ב-GitHub Pages לאחר הפרסום.

לכל שלב כתובת ישירה, למשל #ch-3.
אפשר לערוך את התוכן בקובץ index.html ואת האיורים בתיקיית images.
